# LearnGate Question Quality Evaluation Sheet

## 1. Quality Rubric
Every question generated by local Ollama (`qwen3:4b`) must pass both programmatic contract validation and human pedagogical review.

### Contract Compliance Criteria (Automated)
| Check | Requirement | Fail Condition |
| :--- | :--- | :--- |
| **Option Count** | Exactly 4 options (`options.length === 4`) | Fewer or more than 4 options |
| **Option Uniqueness** | All 4 options are distinct strings | Any duplicate option text |
| **Answer Index** | `answerIndex` is an integer strictly between 0 and 3 | Index `< 0`, `> 3`, or non-integer |
| **Verbatim Sentence** | `sourceSentence` is an exact substring of the user's notes | Paraphrased or altered sentence |
| **ID Format** | Unique identifier starting with `q-` | Missing or non-unique ID |

### Pedagogical Quality Criteria (Manual Review)
| Metric | Rating (1-5) | Description |
| :--- | :--- | :--- |
| **Factual Integrity** | 1 (Wrong) - 5 (Flawless) | Does the indicated correct answer directly and factually follow from the source sentence? |
| **Distractor Plausibility** | 1 (Absurd) - 5 (Excellent) | Are the 3 incorrect options plausible distractors within the subject domain, or obviously fake? |
| **Clarity & Phrasing** | 1 (Confusing) - 5 (Crisp) | Is the question unambiguous, concise, and easy to read under time pressure? |
| **Independence** | 1 (Leaked) - 5 (Fair) | Does the question avoid giving away the answer in the question stem itself? |

## 3. Rejection Guidelines
If a generated question exhibits any of the following, the validation filter in `ollama.js` automatically discards it:
1. The `sourceSentence` does not exist verbatim inside the user notes text (preventing AI hallucinations).
2. Any two options are identical (e.g. `["Metaphase", "Metaphase", "Anaphase", "Telophase"]`).
3. The correct answer option is empty or undefined.
4. The question stem is truncated or ends mid-sentence.
